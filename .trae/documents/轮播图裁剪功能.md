# 轮播图管理添加图片裁剪功能

## 需求分析

当前轮播图管理页面使用 `<image-upload>` 组件上传图片，没有裁剪功能。用户上传的图片尺寸可能不一致，导致轮播图显示效果参差不齐。需要在上传前增加裁剪步骤，确保轮播图图片比例统一。

## 现有资源

- 项目已安装 `vue-cropper@1.1.1`（在 `package.json` 中）
- 项目已有裁剪实现参考：`front/src/views/system/user/profile/userAvatar.vue`（用户头像裁剪）
- 裁剪组件使用方式：`<vue-cropper>` + `getCropBlob()` 获取裁剪结果

## 方案

在轮播图管理页面的新增/编辑弹窗中，将 `<image-upload>` 替换为自定义的裁剪上传流程：

1. 用户点击"选择图片"按钮 → 弹出裁剪弹窗
2. 在裁剪弹窗中选择图片 → 自动进入裁剪模式
3. 裁剪完成后点击"确认上传" → 将裁剪后的图片上传到服务器
4. 上传成功后回显裁剪后的图片

轮播图推荐宽高比 **16:9**（与App端 swiper 高度 320rpx / 宽度比例匹配）。

## 修改文件

### 步骤4：添加裁剪相关的响应式数据和方法

```javascript
const cropperRef = ref(null)
const cropOpen = ref(false)
const cropVisible = ref(false)
const cropUploading = ref(false)
const cropOptions = reactive({
  img: '',
  previews: {},
  filename: ''
})

function getImageUrl(url) {
  if (!url) return ''
  if (url.startsWith('http')) return url
  return import.meta.env.VITE_APP_BASE_API + url
}

function openCropDialog() {
  cropOpen.value = true
}

function onCropOpened() {
  cropVisible.value = true
  if (form.value.image) {
    cropOptions.img = getImageUrl(form.value.image)
  }
}

function onCropClose() {
  cropVisible.value = false
  cropOptions.img = ''
  cropOptions.previews = {}
}

function beforeCropUpload(file) {
  if (file.type.indexOf('image/') === -1) {
    proxy.$modal.msgError('请上传图片文件')
    return false
  }
  const reader = new FileReader()
  reader.readAsDataURL(file)
  reader.onload = () => {
    cropOptions.img = reader.result
    cropOptions.filename = file.name
  }
  return false
}

function changeCropScale(num) {
  cropperRef.value?.changeScale(num)
}

function rotateCropLeft() {
  cropperRef.value?.rotateLeft()
}

function rotateCropRight() {
  cropperRef.value?.rotateRight()
}

function realTimeCrop(data) {
  cropOptions.previews = data
}

async function confirmCrop() {
  if (!cropOptions.img) {
    proxy.$modal.msgError('请先选择图片')
    return
  }
  cropUploading.value = true
  cropperRef.value.getCropBlob(async (blob) => {
    const formData = new FormData()
    formData.append('file', blob, cropOptions.filename || 'banner.jpg')
    try {
      const res = await request({ url: '/common/upload', method: 'post', data: formData })
      if (res.code === 200) {
        form.value.image = res.fileName
        cropOpen.value = false
        cropVisible.value = false
        proxy.$modal.msgSuccess('图片上传成功')
      } else {
        proxy.$modal.msgError(res.msg || '上传失败')
      }
    } catch (e) {
      proxy.$modal.msgError('上传失败')
    } finally {
      cropUploading.value = false
    }
  })
}
```
