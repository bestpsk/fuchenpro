# 裁剪预览与实际显示区域不一致修复

## 问题分析

`vue-cropper` 的 `realTime` 回调返回的 `previews` 对象包含两个样式属性：
- `previews.img` — 预览图片的样式（含 width/height/transform 等）
- `previews.div` — 预览容器的样式（含 width/height/overflow 等）

当前代码只使用了 `previews.img` 绑定到 `<img>` 上，**没有使用 `previews.div`**。`previews.div` 包含了裁剪框对应的容器尺寸和溢出控制，缺少它会导致预览图片的缩放比例和裁剪区域与实际不一致。

`vue-cropper` 官方推荐的预览用法是同时使用 `previews.div` 和 `previews.img`：

```html
<div :style="previews.div">       <!-- 容器样式：控制尺寸和溢出 -->
  <img :src="previews.url" :style="previews.img" />  <!-- 图片样式：控制缩放和位移 -->
</div>
```

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：修改预览区域 HTML，同时使用 previews.div 和 previews.img

```html
<div class="crop-preview">
  <div class="crop-preview-title">预览</div>
  <div class="crop-preview-box">
    <div :style="cropOptions.previews.div" v-if="cropOptions.previews.url">
      <img :src="cropOptions.previews.url" :style="cropOptions.previews.img" />
    </div>
  </div>
</div>
```

### 步骤2：调整预览容器样式

移除 `.crop-preview-box` 中的固定宽高，改为由 `previews.div` 动态控制。`.crop-preview-box` 仅作为外层定位容器：

```scss
.crop-preview-box {
  width: 240px;
  height: 135px;
  border-radius: 8px;
  overflow: hidden;
  border: 1px solid #e5e6eb;
}
```

`previews.div` 会生成类似 `{ width: '240px', height: '135px', overflow: 'hidden', position: 'relative' }` 的样式，内部 `img` 通过 `previews.img` 的 `transform` 实现精确的裁剪预览。
