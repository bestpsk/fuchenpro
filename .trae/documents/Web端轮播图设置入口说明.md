# Web端轮播图设置入口说明

## 操作入口

轮播图管理页面位于管理后台的 **系统管理 > 轮播图管理** 菜单下。

## 前置条件

需要先在数据库中执行 SQL 脚本来创建表和注册菜单权限：

**脚本文件**：`webman/sql/sys_banner.sql`

执行该脚本后会：
1. 创建 `sys_banner` 数据表
2. 在"系统管理"下注册"轮播图管理"菜单（`component: system/banner/index`）
3. 注册4个按钮权限（查询/新增/修改/删除）
4. 为管理员角色分配菜单权限
5. 插入3条默认轮播图数据

## 页面文件

**已创建**：`front/src/views/system/banner/index.vue`

该文件路径与 `sys_menu` 表中 `component` 字段值 `system/banner/index` 对应，管理后台的动态路由机制会自动加载该页面。

## 操作流程

1. 执行 `sys_banner.sql` 脚本
2. 登录管理后台
3. 左侧菜单：**系统管理 > 轮播图管理**
4. 可进行：新增轮播图、修改、删除、启用/停用、调整排序
5. 每张轮播图可设置：标题、图片（上传）、跳转链接、排序号、状态
