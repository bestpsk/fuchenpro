# 裁剪预览比例不一致修复

## 问题分析

当前预览区域使用了 `previews.div` 作为容器样式，但 `previews.div` 生成的尺寸可能不正确（显示为方形而非 16:9）。

对比项目中已正常工作的头像裁剪预览（`userAvatar.vue`），其实现方式是：
- **固定尺寸容器**：200×200，`overflow: hidden`
- **只用 `previews.img`**：不用 `previews.div`
- `previews.img` 包含 `transform` 等样式，能在固定容器内正确定位和缩放图片

## 修复方案

回归头像裁剪的预览模式：固定 16:9 容器 + 只用 `previews.img`，不用 `previews.div`。

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：修改预览区域 HTML

```html
<div class="crop-preview">
  <div class="crop-preview-title">预览</div>
  <div class="crop-preview-box">
    <img :src="cropOptions.previews.url" :style="cropOptions.previews.img" v-if="cropOptions.previews.url" />
  </div>
</div>
```

### 步骤2：修改样式

```scss
.crop-preview-box {
  width: 240px;
  height: 135px;
  border-radius: 8px;
  overflow: hidden;
  position: relative;
  border: 1px solid #e5e6eb;

  img {
    position: absolute;
    top: 0;
    left: 0;
  }
}
```

关键点：
- `width: 240px; height: 135px` — 固定 16:9 比例
- `overflow: hidden` — 裁剪溢出部分
- `position: relative` — 为内部绝对定位的 img 提供参考
- `img` 设 `position: absolute; top: 0; left: 0` — 配合 `previews.img` 的 `transform` 正确定位
