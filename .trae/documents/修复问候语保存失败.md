# 修复问候语保存失败 - 实施计划

## Bug 根因

**两个问题叠加导致保存失败：**

### 问题 1：缺少 `configId`

后端 `SysConfigService::updateConfig()` 第 78 行：
```php
$result = SysConfig::where('config_id', $data['config_id'])->update($data);
```

APP 前端发送的数据：
```js
updateConfig({
  configName: 'APP首页问候语',
  configKey: 'sys.app.welcomeSlogan',
  configValue: sloganInput.value.trim(),
  configType: 'Y'
})
```

**没有 `configId`**！`$data['config_id']` 为 null，`where('config_id', null)` 匹配不到任何记录，`update` 返回 0，`toAjax(0)` 返回失败。

### 问题 2：PUT 请求 body 读取

后端 `edit` 方法用 `$request->post()` 读取数据。在 webman 中，`$request->post()` 对 PUT 请求可能无法正确读取 body（取决于 Content-Type），应使用 `$request->input()` 兼容。

---

## 修复方案

### 步骤 1：后端 - `updateConfig` 支持按 `config_key` 更新

**文件**: `webman/app/service/SysConfigService.php`

当 `config_id` 不存在时，通过 `config_key` 查找记录再更新：

```php
public static function updateConfig($data)
{
    $data['update_time'] = date('Y-m-d H:i:s');
    if (!empty($data['config_id'])) {
        $result = SysConfig::where('config_id', $data['config_id'])->update($data);
    } elseif (!empty($data['config_key'])) {
        $result = SysConfig::where('config_key', $data['config_key'])->update($data);
    } else {
        return false;
    }
    if (!empty($data['config_key'])) {
        $redis = Redis::connection();
        $redis->set(Constants::SYS_CONFIG_KEY . $data['config_key'], $data['config_value'] ?? '');
    }
    return $result;
}
```

### 步骤 2：后端 - `edit` 方法兼容 PUT 请求 body

**文件**: `webman/app/controller/system/SysConfigController.php`

```php
// 修改前
$data = convert_to_snake_case($request->post());

// 修改后
$data = convert_to_snake_case($request->input());
```
