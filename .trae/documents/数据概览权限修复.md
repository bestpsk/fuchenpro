# 数据概览全显示0修复 + 数据权限规划

## 问题分析

1. `order_status = '1'`（企业已审）就算成交，这是正确的，不需要改
2. 全显示0的真正原因可能是：`creator_user_id` 字段在 `biz_sales_order` 表中可能为0或null（新创建的订单可能没有正确设置此字段）
3. 用户需求：每个人看自己的数据，管理层看自己团队的数据

## 数据权限规划

利用项目已有的 `DataScopeService` 和 `sys_role.data_scope` 机制：

| data_scope | 含义 | 统计范围 |
|------------|------|---------|
| 1 | 全部数据 | 看所有人的数据 |
| 2 | 自定义 | 看指定部门的数据 |
| 3 | 本部门 | 看本部门用户的数据 |
| 4 | 本部门及以下 | 看本部门及子部门用户的数据 |
| 5 | 仅本人 | 只看自己的数据 |

实现方式：根据当前用户的角色 `data_scope`，查出可见的用户ID列表，然后用 `whereIn('creator_user_id', $userIds)` 过滤统计。

## 修改文件

`webman/app/service/HomeStatsService.php`

## 实施步骤

### 步骤1：修改 getTodayStats 方法，加入数据权限过滤

```php
public static function getTodayStats($loginUser)
{
    $today = date('Y-m-d');
    $monthStart = date('Y-m-01');

    $userIds = self::getVisibleUserIds($loginUser);

    // 成交客数
    $todayDealCustomers = BizSalesOrder::where('order_status', '1')
        ->whereIn('creator_user_id', $userIds)
        ->whereDate('create_time', $today)
        ->distinct()->count('customer_id');

    $monthDealCustomers = BizSalesOrder::where('order_status', '1')
        ->whereIn('creator_user_id', $userIds)
        ->where('create_time', '>=', $monthStart . ' 00:00:00')
        ->distinct()->count('customer_id');

    // 成交金额
    $todayDealAmount = BizSalesOrder::where('order_status', '1')
        ->whereIn('creator_user_id', $userIds)
        ->whereDate('create_time', $today)
        ->sum('deal_amount');

    $monthDealAmount = BizSalesOrder::where('order_status', '1')
        ->whereIn('creator_user_id', $userIds)
        ->where('create_time', '>=', $monthStart . ' 00:00:00')
        ->sum('deal_amount');

    // 操作客数
    $todayOperationCustomers = BizOperationRecord::whereIn('operator_user_id', $userIds)
        ->whereDate('operation_date', $today)
        ->distinct()->count('customer_id');

    $monthOperationCustomers = BizOperationRecord::whereIn('operator_user_id', $userIds)
        ->where('operation_date', '>=', $monthStart)
        ->distinct()->count('customer_id');

    return [
        'dealCustomerCount' => ['today' => $todayDealCustomers, 'month' => $monthDealCustomers],
        'dealAmount' => ['today' => $todayDealAmount, 'month' => $monthDealAmount],
        'operationCustomerCount' => ['today' => $todayOperationCustomers, 'month' => $monthOperationCustomers],
    ];
}
```

### 步骤2：添加 getVisibleUserIds 方法

根据用户角色的 `data_scope` 计算可见的用户ID列表：

```php
private static function getVisibleUserIds($loginUser)
{
    $userId = $loginUser->userId;

    // 超级管理员看全部
    if ($loginUser->isAdmin()) {
        return BizSalesOrder::distinct()->pluck('creator_user_id')->toArray()
            ?: [$userId];
    }

    // 获取用户角色的最大数据范围
    $dataScope = self::getUserDataScope($loginUser);

    switch ($dataScope) {
        case '1': // 全部数据
            return BizSalesOrder::distinct()->pluck('creator_user_id')->toArray()
                ?: [$userId];

        case '2': // 自定义数据权限
            $deptIds = self::getCustomDeptIds($loginUser);
            return SysUser::whereIn('dept_id', $deptIds)->pluck('user_id')->toArray()
                ?: [$userId];

        case '3': // 本部门
            return SysUser::where('dept_id', $loginUser->deptId)->pluck('user_id')->toArray()
                ?: [$userId];

        case '4': // 本部门及以下
            $deptIds = SysDept::where('dept_id', $loginUser->deptId)
                ->orWhereRaw("FIND_IN_SET(?, ancestors)", [$loginUser->deptId])
                ->pluck('dept_id')->toArray();
            return SysUser::whereIn('dept_id', $deptIds)->pluck('user_id')->toArray()
                ?: [$userId];

        case '5': // 仅本人
        default:
            return [$userId];
    }
}
```

### 步骤4：添加辅助方法

```php
private static function getUserDataScope($loginUser)
{
    $roles = $loginUser->user->roles ?? [];
    $maxScope = '5';
    foreach ($roles as $role) {
        if (isset($role->data_scope) && $role->data_scope < $maxScope) {
            $maxScope = $role->data_scope;
        }
    }
    return $maxScope;
}

private static function getCustomDeptIds($loginUser)
{
    $roles = $loginUser->user->roles ?? [];
    $roleIds = collect($roles)->pluck('role_id')->toArray();
    if (empty($roleIds)) return [];
    return SysRoleDept::whereIn('role_id', $roleIds)->pluck('dept_id')->toArray();
}
```
