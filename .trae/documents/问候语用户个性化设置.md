# 问候语用户个性化设置 - 实施计划

## 需求变更

每个用户可以设置自己的问候语，而不是管理员统一设置。

## 方案

在已有的 `sys_user_detail` 表中新增 `welcome_slogan` 字段，复用现有的用户详情 API。

### 为什么选 `sys_user_detail`？

- 已有 `SysUserDetail` 模型和 CRUD API（`/system/user/detail`）
- 已有一对一关联 `SysUser::detail()`
- 不需要新建表或新 API

---

## 实施步骤

### 步骤 1：数据库 - `sys_user_detail` 表新增 `welcome_slogan` 字段

```sql
ALTER TABLE sys_user_detail ADD COLUMN welcome_slogan VARCHAR(50) DEFAULT NULL COMMENT '首页问候语' AFTER address;
```

### 步骤 2：后端 - `SysUserDetail` 模型添加 `welcome_slogan` 到 fillable

**文件**: `webman/app/model/SysUserDetail.php`

```php
protected $fillable = [
    'user_id', 'wechat', 'birthday', 'id_card', 'address', 'welcome_slogan',
    'hire_date', 'employment_status', 'resign_date',
    'create_by', 'create_time', 'update_by', 'update_time', 'remark'
];
```

### 步骤 3：后端 - 新增获取/设置问候语的便捷接口

**文件**: `webman/app/controller/system/SysUserDetailController.php`

新增两个方法：
- `GET /system/user/detail/welcomeSlogan` - 获取当前用户问候语
- `PUT /system/user/detail/welcomeSlogan` - 设置当前用户问候语

**文件**: `webman/config/route.php` - 注册新路由

### 步骤 4：APP 端 - API 层新增问候语接口

**文件**: `AppV3/src/api/system/config.js`

```js
export function getWelcomeSlogan() {
  return request({ url: '/system/user/detail/welcomeSlogan', method: 'get' })
}

export function setWelcomeSlogan(welcomeSlogan) {
  return request({ url: '/system/user/detail/welcomeSlogan', method: 'put', data: { welcomeSlogan } })
}
```

### 步骤 5：APP 端 - HeaderNav 从用户详情读取问候语

**文件**: `AppV3/src/components/home/HeaderNav.vue`

- 替换 `getConfigKey('sys.app.welcomeSlogan')` 为 `getWelcomeSlogan()`
- 优先读本地缓存，再从 API 获取

### 步骤 6：APP 端 - 设置页保存问候语改用新接口

**文件**: `AppV3/src/pages/mine/setting/index.vue`

- 替换 `updateConfig(...)` 为 `setWelcomeSlogan(...)`

### 步骤 7：清理 - 移除 `sys_config` 中的全局问候语配置

删除之前插入的 `sys.app.welcomeSlogan` 配置项（不再需要）。
