# 预览图偏移修复

## 问题分析

预览图"偏右"、"只显示左上一小部分"的原因：

`vue-cropper` 的 `realTime` 回调返回的 `previews.img` 样式包含 `margin-left`、`margin-top` 和 `transform` 等属性，用于在预览容器中正确定位图片。这些 margin 值是 vue-cropper 根据裁剪框位置和预览容器尺寸计算出来的。

但我们在 CSS 中给 img 设置了 `position: absolute; top: 0; left: 0`，这会：
1. **覆盖 margin 值** — absolute 定位使 margin 失效，图片被强制定位到容器左上角
2. **transform 冲突** — `previews.img` 的 `transform`（含 translate 偏移）与 absolute 定位叠加，导致图片偏移

对比项目中正常工作的头像裁剪预览（`userAvatar.vue`），其 img **没有任何 CSS 定位**，完全依赖 `previews.img` 的 margin 和 transform 来定位。

## 修复方案

移除 img 上的 `position: absolute; top: 0; left: 0`，让 `previews.img` 的 margin 和 transform 自行控制图片位置。

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：移除 img 的绝对定位样式

```scss
.crop-preview-box {
  width: 240px;
  height: 135px;
  border-radius: 8px;
  overflow: hidden;
  border: 1px solid #e5e6eb;
}
```

移除 `position: relative`（不再需要）和 `img { position: absolute; top: 0; left: 0 }`。
