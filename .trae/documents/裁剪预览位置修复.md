# 裁剪弹窗预览图片位置错误修复

## 问题分析

裁剪弹窗中右侧预览图片显示在弹窗上方而非弹窗内部。

**根因**：`vue-cropper` 的 `@realTime` 回调返回的 `previews.img` 是一个内联样式对象（包含 `width`、`height`、`overflow`、`transform` 等），这些样式用于在预览容器中模拟裁剪框的缩放和位移。但预览图片的样式没有 `position: absolute` 配合父容器的 `position: relative; overflow: hidden`，导致图片按文档流渲染，溢出到弹窗外部。

对比项目中已有的头像裁剪实现（`userAvatar.vue`），其预览区域使用 `.avatar-upload-preview` 类，该类在全局样式中定义了 `position: relative; overflow: hidden` 来约束预览图片。

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：修改预览区域 HTML 结构

给预览图片添加一个固定尺寸的容器，设置 `position: relative; overflow: hidden`：

```html
<el-col :span="8" style="height: 400px; display: flex; align-items: center; justify-content: center">
  <div class="crop-preview">
    <div class="crop-preview-title">预览</div>
    <div class="crop-preview-box" v-if="cropOptions.previews.url">
      <img :src="cropOptions.previews.url" :style="cropOptions.previews.img" />
    </div>
  </div>
</el-col>
```

### 步骤2：添加预览容器样式

```scss
.crop-preview-box {
  width: 240px;
  height: 135px;
  border-radius: 8px;
  overflow: hidden;
  position: relative;
  border: 1px solid #e5e6eb;

  img {
    position: absolute;
    top: 0;
    left: 0;
  }
}
```

关键点：
- `position: relative` + `overflow: hidden` — 约束预览图片不溢出容器
- `width: 240px; height: 135px` — 16:9 比例的预览尺寸
- `img` 设置 `position: absolute` — 配合 `previews.img` 中的 `transform` 样式正确工作
