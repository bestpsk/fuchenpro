# 创建顾客后头像不显示 - 修复计划

## 问题根因

### 根因1：`addCustomer` 不返回新客户ID，头像上传被跳过

后端 `BizCustomerController::add()` 使用 `AjaxResult::toAjax($result ? 1 : 0)`，返回：
```json
{ "code": 200, "msg": "操作成功" }
```

**不包含任何客户数据**（没有 `customerId`），所以前端 `res?.data?.customerId` 为 `undefined`，`newCustomerId` 为 `undefined`，头像上传的 `if (newCustomerId && customerAvatarPreview.value)` 条件不满足，**头像上传被跳过**。

### 根因2：头像URL可能是相对路径，需要拼接baseUrl

后端 `avatar()` 方法返回的 `imgUrl` 可能是相对路径（如 `/profile/customer_avatar/xxx.png`），但 `searchCustomer` 返回的 `avatar` 字段也是相对路径。`<u-avatar :src="item.avatar">` 在移动端无法直接访问相对路径，需要拼接 `baseUrl`。

## 修复方案

### 步骤1：修改后端 `add()` 方法，返回新创建的客户ID

```php
public function add(Request $request)
{
    $data = convert_to_snake_case($request->post());
    $data['create_by'] = $request->loginUser->user->user_name ?? '';
    $service = new BizCustomerService();
    $result = $service->insertCustomer($data);
    if ($result) {
        return AjaxResult::success('', ['customerId' => $result->customer_id]);
    }
    return AjaxResult::error('新增客户失败');
}
```

### 步骤2：修复前端头像URL拼接

在客户列表和首页订单列表中，当 `avatar` 是相对路径时，需要拼接 `baseUrl`。

### 步骤3：修复首页订单列表的头像映射

首页 `loadHomeData()` 中归档数据映射时，需要从归档记录中获取客户头像。但归档表没有 `avatar` 字段，需要从客户信息反查，或者使用客户名首字文字头像（当前已实现）。
