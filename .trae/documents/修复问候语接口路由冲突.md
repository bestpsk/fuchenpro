# 修复问候语接口系统未知错误 - 实施计划

## Bug 根因

**路由匹配冲突**：`GET /system/user/detail/welcomeSlogan` 被 `GET /system/user/detail/{userId}` 先匹配到。

路由注册顺序：
```
第 273 行: GET /system/user/detail/{userId}       ← 先注册，先匹配
第 276 行: GET /system/user/detail/welcomeSlogan   ← 永远不会被执行
```

当请求 `/system/user/detail/welcomeSlogan` 时，webman 路由将 `welcomeSlogan` 当作 `{userId}` 参数，匹配到 `getInfo` 方法。`intval('welcomeSlogan')` = `0`，`selectDetailByUserId(0)` 返回 null。

PUT 请求同样存在此问题。

## 修复方案

将 `welcomeSlogan` 的两条路由移到 `{userId}` 路由**之前**，确保精确匹配优先于动态参数匹配。

**文件**: `webman/config/route.php`

```php
// 修改前
Route::get('/system/user/detail/{userId}', ...);
Route::post('/system/user/detail', ...);
Route::put('/system/user/detail', ...);
Route::get('/system/user/detail/welcomeSlogan', ...);
Route::put('/system/user/detail/welcomeSlogan', ...);

// 修改后
Route::get('/system/user/detail/welcomeSlogan', ...);
Route::put('/system/user/detail/welcomeSlogan', ...);
Route::get('/system/user/detail/{userId}', ...);
Route::post('/system/user/detail', ...);
Route::put('/system/user/detail', ...);
```
