# 最近订单 - 显示开单员工 + 客户头像处理

## 需求
1. 最近订单列表中需要显示"开单员工"
2. 客户头像在哪里设置？目前是硬编码的默认头像

## 现状分析

### 客户头像
- `biz_customer` 表**没有 avatar 字段**，数据库中不存在客户头像
- 首页 `index.vue:86` 硬编码 `avatar: '/static/images/profile.jpg'`，所有客户显示同一张默认图
- 客户创建表单（PC端和App端）都没有头像上传功能
- 系统用户（`sys_user`）有 `avatar` 字段，但客户没有

### 开单员工
- 归档表 `biz_customer_archive` 已有 `operator_user_name` 字段，数据写入时已自动填充
- 首页 `index.vue:82-92` 映射归档数据时，**没有映射 `operator_user_name`**
- `OrderList.vue` 组件没有显示开单员工的UI

## 修改方案

### 步骤1：首页数据映射 - 补充开单员工字段

在 `index.vue` 的 `loadHomeData()` 中，映射 `operatorUserName`：

```javascript
orderList.value = (archiveRes.rows || []).map(item => ({
  ...existing fields,
  operatorName: item.operatorUserName || item.operator_user_name || '',  // 新增
}))
```

### 步骤2：OrderList.vue - 新增开单员工显示

在客户名称和门店之间，新增一行显示开单员工：

```
[头像] 客户名 [来源标签]
       开单员工: xxx
       🏠 门店名
```

### 步骤3：客户头像 - 使用客户名首字作为文字头像

由于 `biz_customer` 表没有 avatar 字段，且添加头像功能涉及全栈改动较大，建议：
- 使用 `<u-avatar>` 的文字模式，显示客户名第一个字
- 当有真实头像时显示图片，否则显示文字头像
- 这样无需数据库改动即可区分不同客户
