# AppV3 供货商管理实现计划

## 一、需求概述

在 AppV3 移动端实现"供货商管理"功能，借鉴 Web 端 `front/src/views/wms/supplier/index.vue` 的功能，适配移动端交互，界面要求扁平化高级感。

## 二、现有资源

### 后端接口（已就绪，无需修改）

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 供货商列表 | GET | `/wms/supplier/list` | 分页查询，支持 supplierName/contactPerson/status 筛选 |
| 供货商搜索 | GET | `/wms/supplier/search` | 关键词搜索（下拉选择用），仅返回正常状态 |
| 供货商详情 | GET | `/wms/supplier/{supplierId}` | 获取详情 |
| 新增供货商 | POST | `/wms/supplier` | 新增 |
| 修改供货商 | PUT | `/wms/supplier` | 修改 |
| 删除供货商 | DELETE | `/wms/supplier` | 批量删除 |

### 数据模型

```
supplierId          -- 供货商ID（主键）
supplierName        -- 供货商名称（必填）
contactPerson       -- 联系人
contactPhone        -- 联系电话
address             -- 地址
cooperationStartDate -- 合作起始日期
status              -- 状态(0正常 1停用)
remark              -- 备注
```

### 菜单配置

`menu.js` 中 wms 分组已有"供货商管理"菜单项（id=60），但 path 为空，需更新路径。

## 三、页面规划

### 3.1 供货商列表页 — `pages/wms/supplier/index.vue`

**扁平化高级感设计要点**：
- 搜索区使用更轻量的设计，去掉渐变背景，改为白色卡片式搜索
- 卡片采用极简风格，减少视觉噪音，信息层次分明
- 状态标签使用更精致的胶囊样式

**布局结构**：
```
┌─────────────────────────────────┐
│  搜索区（白色背景，轻量设计）     │
│  [🔍 搜索供货商名称/联系人] [筛选]│
├─────────────────────────────────┤
│  筛选弹窗 (u-popup top)          │
│  状态: [全部][正常][停用]         │
│  [重置] [确定]                   │
├─────────────────────────────────┤
│  scroll-view 列表区域            │
│  ┌─────────────────────────────┐│
│  │ 南京伊美荟          [正常]   ││ ← 卡片 header: 名称 + 状态
│  │ 👤 张经理  📞 138xxxx       ││ ← 卡片 body: 联系人 + 电话
│  │ 📍 南京市...  📅 2026-01-01 ││ ← 地址 + 合作日期
│  └─────────────────────────────┘│
│  u-loadmore                     │
├─────────────────────────────────┤
│  [+] FAB 新增按钮               │
└─────────────────────────────────┘
```

**核心功能**：
- 关键词搜索（供货商名称/联系人模糊匹配）
- 状态筛选（正常/停用）
- 分页加载（下拉刷新 + 上拉加载更多）
- 卡片点击进入详情页
- 电话号码可点击拨打
- FAB 按钮跳转新增

### 3.2 供货商表单页 — `pages/wms/supplier/form.vue`

**布局结构**：
```
┌─────────────────────────────────┐
│  供货商信息卡片                  │
│  🏢 [供货商名称________]        │
│  👤 [联系人__________]           │
│  📞 [联系电话________]          │
│  📍 [地址____________]          │
│  📅 [合作起始日期    ▶]         │
│  ○ 正常  ○ 停用                │
│  📝 [备注____________]          │
├─────────────────────────────────┤
│  [取消]              [保存]      │ ← 固定底部操作栏
└─────────────────────────────────┘
```

**核心功能**：
- 支持 add/edit/view 三种模式
- 供货商名称必填校验
- 联系电话格式校验（11位手机号）
- 日期选择器（合作起始日期）
- 状态单选（正常/停用）
- 保存成功后返回列表页

## 六、扁平化高级感设计要点

1. **搜索区**：白色背景替代蓝色渐变，更轻量简洁
2. **卡片**：减少阴影和边框，用留白和微妙的背景色区分层次
3. **状态标签**：使用精致的胶囊样式，颜色更柔和
4. **信息行**：去掉图标前缀，用文字标签+值的方式，更干净
5. **配色**：以灰阶为主，绿色系（#10B981）作为进销存模块的强调色
6. **间距**：更大的留白，呼吸感更强
