# 外勤事由输入框卡片溢出修复计划

## 问题分析

从截图可见，**外勤事由卡片（outside-card）右侧超出容器边界**，而同页面的定位卡片（location-card）显示正常。

对比两个卡片的样式差异：

| 样式属性 | location-card（正常） | outside-card（溢出） |
|---------|---------------------|---------------------|
| `box-sizing` | 未显式设置 | 已设 `border-box` |
| `overflow` | **`hidden`** ✅ | ❌ 缺失 |
| `border` | `1rpx solid rgba(0,0,0,0.04)` | 无 |

**根因**：`.outside-card` 缺少 `overflow: hidden`，且可能需要确保宽度计算正确。另外输入框高度 `120rpx` 在视觉上仍然偏大，需进一步缩小。

## 修改文件

`AppV3/src/pages/attendance/index.vue`

## 实施步骤

### 步骤1：给 .outside-card 添加 overflow: hidden

防止内容撑破卡片边界。

```scss
.outside-card {
  // ... 现有样式
  box-sizing: border-box;
  overflow: hidden;   // 新增
}
```

### 步骤2：进一步缩小输入框高度

当前 `120rpx` → 调整为 `100rpx`，使外勤事由区域更紧凑。

```scss
.outside-input {
  height: 100rpx;    // 从 120rpx 改为 100rpx
}
```
