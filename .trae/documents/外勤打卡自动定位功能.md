# 外勤打卡自动定位功能实施计划

## 需求分析

当前考勤打卡页面中，**坐班打卡**会在页面加载时自动获取GPS定位并展示定位卡片（含地址、距考勤点距离、刷新按钮等），而**外勤打卡**完全没有定位功能，只要求填写事由和拍照。

**目标**：让外勤打卡也像坐班打卡一样自动定位，记录外勤打卡的实际位置信息。

## 现状对比

| 功能 | 坐班打卡 (clockType='0') | 外勤打卡 (clockType='1') |
|------|-------------------------|-------------------------|
| 定位卡片 | ✅ 显示 (`v-if="clockType === '0'"`) | ❌ 不显示 |
| 自动定位 | ✅ 页面加载自动执行 | ❌ 无 |
| 距离计算 | ✅ 计算距考勤点距离 | ❌ 无 |
| 手动输入地址 | ✅ 定位失败可手动输入 | ❌ 无 |
| 打卡条件 | 需定位或手动地址 | 仅需事由+照片 |
| 提交参数 | 含经纬度+地址 | 不含定位数据 |

## 修改文件

仅需修改一个文件：`AppV3/src/pages/attendance/index.vue`

后端无需修改——`BizAttendanceRecordService.php` 的 `clock()` 方法已支持外勤打卡携带经纬度/地址参数，只是前端不传。

## 实施步骤

### 步骤1：定位卡片对外勤打卡也可见

**位置**：模板第19行

将定位卡片的 `v-if="clockType === '0'"` 改为 `v-if="clockType === '0' || clockType === '1'"`，或直接移除该条件（因为定位卡片在两种模式下都应显示）。

**具体改动**：
```html
<!-- 修改前 -->
<view class="location-card" v-if="clockType === '0'" ...>

<!-- 修改后 -->
<view class="location-card" v-if="clockType === '0' || clockType === '1'" ...>
```

### 步骤2：调整定位卡片中外勤模式的展示内容

外勤打卡不需要显示"距考勤点距离"（因为外勤本身就不在公司），但应显示当前定位地址。

**具体改动**：
- 距离显示行：添加条件 `v-if="clockType === '0'"`，仅坐班模式显示距考勤点距离
- 外勤模式下，定位成功后显示"已获取当前位置"的提示
- 刷新按钮两种模式都保留

### 步骤3：修改 canClock 计算属性

**位置**：脚本第231-241行

外勤打卡的 `canClock` 条件增加定位要求：除了事由和照片外，还需要有定位坐标或手动地址。

**具体改动**：
```javascript
// 修改前
if (clockType.value === '1') {
  return !!(outsideReason.value.trim() && photoUploadedUrl.value)
}

// 修改后
if (clockType.value === '1') {
  return !!(outsideReason.value.trim() && photoUploadedUrl.value && (location.value.latitude || manualAddress.value.trim()))
}
```

### 步骤4：修改 handleClockClick 中的提示逻辑

**位置**：脚本第697-716行

外勤打卡校验不通过时，增加定位相关的提示。

**具体改动**：
```javascript
// 外勤打卡校验提示增加定位判断
else if (clockType.value === '1') {
  if (!location.value.latitude && !manualAddress.value.trim()) {
    uni.showToast({ title: '请先获取定位或手动输入地址', icon: 'none' })
  } else if (!outsideReason.value.trim()) {
    uni.showToast({ title: '请填写外勤事由', icon: 'none' })
  } else if (!photoUploadedUrl.value) {
    uni.showToast({ title: '外勤打卡必须拍照', icon: 'none' })
  }
}
```

### 步骤5：修改 handleClock 中的校验逻辑

**位置**：脚本第602-619行

外勤打卡提交前增加定位校验。

**具体改动**：
```javascript
// 在 clockType === '1' 的校验块中增加定位检查
if (clockType.value === '1') {
  if (!location.value.latitude && !manualAddress.value.trim()) {
    uni.showToast({ title: '请先获取定位或手动输入地址', icon: 'none' })
    return
  }
  if (!outsideReason.value.trim()) { ... }
  if (!photoUploadedUrl.value) { ... }
}
```

### 步骤6：调整定位卡片样式适配外勤模式

外勤模式下定位卡片可以有不同的视觉提示，例如：
- 定位成功时，坐班显示绿色边框+距考勤点距离，外勤显示蓝色边框+当前位置
- 可通过动态 class 绑定实现

## 改动汇总

| 改动点 | 文件 | 行号 | 说明 |
|--------|------|------|------|
| 定位卡片可见性 | index.vue | 19 | `v-if` 条件增加外勤模式 |
| 距离显示条件 | index.vue | 38-41 | 仅坐班模式显示距考勤点距离 |
| canClock 条件 | index.vue | 236-238 | 外勤增加定位要求 |
| handleClockClick 提示 | index.vue | 705-710 | 增加定位失败提示 |
| handleClock 校验 | index.vue | 610-619 | 增加定位校验 |

## 不需要改动的部分

- **后端**：`BizAttendanceRecordService.php` 的 `clock()` 方法已接受 latitude/longitude/address 参数，外勤打卡携带定位数据无需后端修改
- **API层**：`attendance.js` 无需修改，打卡接口参数已包含定位字段
- **数据库**：`biz_attendance_record` 和 `biz_attendance_clock` 表已有经纬度/地址字段
- **管理后台**：考勤记录查看页已能展示打卡位置信息
