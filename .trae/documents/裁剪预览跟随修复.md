# 裁剪预览与裁剪框不一致修复

## 问题分析

`vue-cropper` 的 `realTime` 回调返回的 `previews` 对象：
- `previews.url` — 预览图片的 base64 URL
- `previews.img` — 图片样式（width/height/transform/margin 等）
- `previews.div` — 容器样式（width/height/overflow/position 等）

`previews.div` 和 `previews.img` 的尺寸是基于裁剪框在原图上的实际像素比例动态计算的，不是固定值。当用户拖动裁剪框改变大小时，`previews.div` 的宽高会跟着变化。

但当前外层 `.crop-preview-box` 是固定的 240×135，`previews.div` 的动态尺寸与固定外层容器冲突，导致预览图片不能正确跟随裁剪框大小变化。

## 修复方案

**移除固定的 `.crop-preview-box` 外层容器**，直接使用 `previews.div` 作为预览容器。`previews.div` 本身已包含 `overflow: hidden; position: relative` 等样式，可以独立工作。同时给预览区域设置 `max-width` 和 `max-height` 防止溢出。

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：修改预览区域 HTML

移除 `.crop-preview-box`，直接使用 `previews.div` 作为容器：

```html
<div class="crop-preview">
  <div class="crop-preview-title">预览</div>
  <div class="crop-preview-wrap" v-if="cropOptions.previews.url">
    <div :style="cropOptions.previews.div">
      <img :src="cropOptions.previews.url" :style="cropOptions.previews.img" />
    </div>
  </div>
</div>
```

### 步骤2：修改样式

将 `.crop-preview-box` 替换为 `.crop-preview-wrap`，仅做居中和最大尺寸限制：

```scss
.crop-preview-wrap {
  display: flex;
  align-items: center;
  justify-content: center;
  max-width: 100%;

  > div {
    max-width: 100%;
    max-height: 300px;
    border-radius: 8px;
    overflow: hidden;
    border: 1px solid #e5e6eb;
  }
}
```

这样 `previews.div` 生成的容器尺寸会跟随裁剪框动态变化，预览图片始终与裁剪框选中的区域一致。
