# 问候语配置管理入口 - 实施计划

## 现状

- `sys.app.welcomeSlogan` 配置项已存入数据库
- Web 端"系统管理 → 参数设置"页面可以修改，但需要知道键名，对非技术用户不友好
- APP 端设置页面（`/pages/mine/setting/index`）只有修改密码、检查更新、清理缓存、退出登录，无问候语设置

## 方案

在 APP 端设置页面增加"首页问候语"设置项，管理员可直接在 APP 中修改，保存后立即生效。

### 步骤 1：APP 端 - 设置页面增加问候语设置项

**修改文件**: `AppV3/src/pages/mine/setting/index.vue`

在"修改密码"和"检查更新"之间增加"首页问候语"设置项：
- 点击后弹出输入框（`uni.showModal` 或自定义弹窗）
- 输入新问候语后调用 `updateConfig` API 保存
- 保存成功后更新本地缓存，下次进入首页即生效

需要新增 `updateConfig` API：

**修改文件**: `AppV3/src/api/system/config.js`

```js
export function updateConfig(data) {
  return request({ url: '/system/config', method: 'put', data })
}
```

### 步骤 2：APP 端 - HeaderNav 加载问候语时优先读本地缓存

**修改文件**: `AppV3/src/components/home/HeaderNav.vue`

将 `loadWelcomeSlogan` 改为：先从本地缓存取（快速显示），再从 API 获取（确保最新）。

```js
function loadWelcomeSlogan() {
  const cached = uni.getStorageSync('welcome_slogan')
  if (cached) welcomeSlogan.value = cached
  getConfigKey('sys.app.welcomeSlogan').then(res => {
    if (res.data) {
      welcomeSlogan.value = res.data
      uni.setStorageSync('welcome_slogan', res.data)
    }
  }).catch(() => {})
}
```

### 步骤 3：APP 端 - 设置页保存问候语后通知首页刷新

**修改文件**: `AppV3/src/pages/mine/setting/index.vue`

保存成功后：
1. 更新本地缓存 `uni.setStorageSync('welcome_slogan', newValue)`
2. 通过 `uni.$emit('welcomeSloganChanged')` 通知首页

**修改文件**: `AppV3/src/components/home/HeaderNav.vue`

在 `onMounted` 中监听事件：
```js
uni.$on('welcomeSloganChanged', () => loadWelcomeSlogan())
```
