# 问候语可自定义 - 实施计划

## 需求

将首页问候语 `晚上好，开启美好的一天！` 中的"开启美好的一天"部分改为可配置，管理员可在系统管理中自定义。

## 方案

利用现有的 `sys_config` 系统参数配置机制，新增一个配置项 `sys.app.welcomeSlogan`，存储自定义问候语后缀。前端从后端动态读取。

---

## 实施步骤

### 步骤 1：数据库 - 插入新配置项

向 `sys_config` 表插入一条记录：

```sql
INSERT INTO sys_config (config_name, config_key, config_value, config_type, create_by, create_time, remark)
VALUES ('APP首页问候语', 'sys.app.welcomeSlogan', '开启美好的一天', 'Y', 'admin', NOW(), 'APP首页欢迎文字后缀，如"开启美好的一天"');
```

`config_type = 'Y'` 表示系统内置（不可随意删除），管理员可在"系统管理 → 参数设置"中修改。

### 步骤 2：APP 端 - 新增 getConfigKey API

**新建文件**: `AppV3/src/api/system/config.js`

```js
import request from '@/utils/request'

export function getConfigKey(configKey) {
  return request({ url: '/system/config/configKey/' + configKey, method: 'get' })
}
```

### 步骤 3：APP 端 - HeaderNav 动态读取问候语

**修改文件**: `AppV3/src/components/home/HeaderNav.vue`

- 引入 `getConfigKey` API
- 新增 `welcomeSlogan` ref，默认值 `'开启美好的一天'`
- `onMounted` 时调用 `getConfigKey('sys.app.welcomeSlogan')` 获取自定义值
- 模板中 `{{ greeting }}，开启美好的一天！` → `{{ greeting }}，{{ welcomeSlogan }}！`

### 步骤 4：Web 前端 - 首页同步适配（如有需要）

Web 端首页如果也展示类似问候语，同样通过 `getConfigKey` 读取。当前 Web 首页无此文案，此步骤可跳过。
