# 客户头像功能 - 全栈实现计划

## 需求
1. 客户列表中显示头像
2. 创建/编辑客户时可以上传头像

## 现状
- `biz_customer` 表**没有 avatar 字段**
- AppV3 客户列表用性别图标代替头像
- PC端客户列表用 👤 emoji 代替头像
- 两端均无客户编辑功能，只有新增
- 系统用户头像已有完整上传机制（`SysUserController::avatar()`），支持COS和本地存储

## 修改方案

### 步骤1：数据库 - 新增 avatar 字段

```sql
ALTER TABLE `biz_customer` ADD COLUMN `avatar` varchar(500) DEFAULT '' COMMENT '客户头像' AFTER `customer_name`;
```

### 步骤2：后端模型 - BizCustomer.php 添加 avatar 到 $fillable

在 `$fillable` 数组中 `customer_name` 后添加 `'avatar'`。

### 步骤3：后端控制器 - BizCustomerController 新增 avatar 上传接口

参考 `SysUserController::avatar()` 的实现，新增客户头像上传接口：

```php

{
    $customerId = $request->post('customer_id');
    $file = $request->file('avatarfile');
    // 上传逻辑（COS优先，本地兜底）
    // 更新 biz_customer 的 avatar 字段
}
```

路由：`POST /business/customer/avatar`

### 步骤4：AppV3 客户列表 - 显示头像

修改 `sales/index.vue` 客户卡片，将性别图标改为头像：
- 有 avatar → 显示图片头像
- 无 avatar → 显示文字头像（客户名首字，蓝底白字/粉底白字按性别区分）

### 步骤5：AppV3 新增客户弹窗 - 添加头像上传

在 `sales/index.vue` 的新增客户弹窗中，添加头像上传区域：
- 使用 `uni.chooseImage` 选择图片
- 调用 `/business/customer/avatar` 上传
- 创建客户时传入 avatar URL

### 步骤6：PC端客户列表 - 显示头像

修改 `front/src/views/business/sales/index.vue` 客户列表项，将 👤 emoji 改为 `el-avatar`：
- 有 avatar → 显示图片
- 无 avatar → 显示文字头像（客户名首字）

### 步骤7：PC端新增客户弹窗 - 添加头像上传

在 `front/src/views/business/sales/index.vue` 的新增客户弹窗中，添加 `el-upload` 头像上传组件。
