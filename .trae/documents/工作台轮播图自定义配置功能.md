# 工作台轮播图自定义配置功能实施计划

## 需求分析

当前工作台轮播图是硬编码的3张静态图片，无法通过管理后台动态配置。需要实现：
- 管理员可在后台新增/编辑/删除/排序轮播图
- 每张轮播图支持设置：图片、标题、跳转链接、排序号、启用状态
- App端工作台从后端接口动态获取轮播图数据
- 点击轮播图可跳转到指定链接

## 现状

| 层级 | 现状 | 需要改动 |
|------|------|---------|
| 数据库 | 无轮播图表 | 新建 `sys_banner` 表 |
| 后端 Model | 无 | 新建 `SysBanner.php` |
| 后端 Service | 无 | 新建 `SysBannerService.php` |
| 后端 Controller | 无 | 新建 `SysBannerController.php` |
| 后端路由 | 无 | 注册5条路由 + 1条App端公开路由 |
| 管理后台 API | 无 | 新建 `api/system/banner.js` |
| 管理后台页面 | 无 | 新建 `views/system/banner/index.vue` |
| App端 API | 无 | 在 `api/home.js` 中新增接口 |
| App端页面 | 硬编码3张图片 | 改为从接口动态获取 |
| 菜单权限 | 无 | 插入菜单和按钮权限数据 |

## 实施步骤

### 步骤1：创建数据库表和菜单权限（SQL脚本）

**文件**：`webman/sql/sys_banner.sql`

```sql
-- 1. 创建轮播图表
CREATE TABLE `sys_banner` (
  `banner_id` bigint NOT NULL AUTO_INCREMENT COMMENT '轮播图ID',
  `title` varchar(100) DEFAULT '' COMMENT '标题',
  `image` varchar(500) NOT NULL COMMENT '图片地址',
  `link_url` varchar(500) DEFAULT '' COMMENT '跳转链接',
  `sort_order` int NOT NULL DEFAULT 0 COMMENT '排序号(越小越前)',
  `status` char(1) NOT NULL DEFAULT '0' COMMENT '状态(0正常 1停用)',
  `remark` varchar(500) DEFAULT '' COMMENT '备注',
  `create_by` varchar(64) DEFAULT '' COMMENT '创建者',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_by` varchar(64) DEFAULT '' COMMENT '更新者',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`banner_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='轮播图表';

-- 2. 插入菜单（放在系统管理下）
-- 3. 插入按钮权限
-- 4. 分配管理员角色权限
-- 5. 插入默认轮播图数据
```

### 步骤2：创建后端 Model

**文件**：`webman/app/model/SysBanner.php`

- 继承 `support\Model`
- `$table = 'sys_banner'`
- `$primaryKey = 'banner_id'`
- `$timestamps = false`
- `$fillable` 包含所有可写字段

### 步骤3：创建后端 Service

**文件**：`webman/app/service/SysBannerService.php`

标准五件套方法：
- `selectBannerList($params)` — 分页列表，支持按标题/状态筛选
- `selectBannerById($bannerId)` — 详情
- `insertBanner($data)` — 新增
- `updateBanner($data)` — 修改
- `deleteBannerByIds($bannerIds)` — 批量删除
- `selectEnabledBanners()` — **App端专用**：查询所有启用的轮播图，按 sort_order 排序

### 步骤4：创建后端 Controller

**文件**：`webman/app/controller/system/SysBannerController.php`

标准五件套 + App端接口：
- `list()` — 管理后台分页列表
- `getInfo()` — 详情
- `add()` — 新增
- `edit()` — 修改
- `remove()` — 删除

### 步骤5：注册后端路由

**文件**：`webman/config/route.php`

```php
// 管理后台轮播图CRUD
Route::get('/system/banner/list', [SysBannerController::class, 'list']);
Route::get('/system/banner/{bannerId}', [SysBannerController::class, 'getInfo']);
Route::post('/system/banner', [SysBannerController::class, 'add']);
Route::put('/system/banner', [SysBannerController::class, 'edit']);
Route::delete('/system/banner', [SysBannerController::class, 'remove']);

// App端公开接口（无需登录）
Route::get('/app/banner/list', [SysBannerController::class, 'appList']);
```

### 步骤6：创建管理后台 API

**文件**：`front/src/api/system/banner.js`

标准五件套：`listBanner`、`getBanner`、`addBanner`、`updateBanner`、`delBanner`

### 步骤7：创建管理后台轮播图配置页面

**文件**：`front/src/views/system/banner/index.vue`

页面结构：
- **搜索栏**：按标题搜索、按状态筛选
- **操作栏**：新增按钮、修改按钮、删除按钮
- **数据表格**：ID、图片缩略图(`<image-preview>`)、标题、跳转链接、排序号、状态(`<el-switch>`)、创建时间、操作列
- **分页器**：标准 `<pagination>` 组件
- **新增/编辑弹窗**：标题、图片上传(`<image-upload>`)、跳转链接、排序号、状态、备注

### 步骤8：App端 API 新增接口

**文件**：`AppV3/src/api/home.js`

新增 `getBannerList()` 函数，调用 `/app/banner/list` 接口。

### 步骤9：App端工作台页面改造

**文件**：`AppV3/src/pages/work/index.vue`

改动：
1. 将硬编码的 `bannerList` 改为从接口动态获取
2. `bannerList` 数据结构增加 `title`、`linkUrl` 字段
3. `clickBannerItem` 实现跳转逻辑（有 linkUrl 则跳转，无则忽略）
4. 页面加载时调用 `getBannerList()` 获取数据
5. 接口失败时 fallback 到默认静态图片（保证体验）

### 步骤10：App端路由白名单

**文件**：`webman/app/middleware/AuthMiddleware.php`

将 `/app/banner/list` 加入白名单，使App端无需登录即可获取轮播图数据（因为工作台页面在登录后也会显示，但为简化逻辑，也可以不加白名单，由前端在已登录状态下请求）。

> **决策**：轮播图接口不需要加入白名单。因为App端工作台是登录后才能访问的页面，请求时已携带Token，走正常认证流程即可。这样更安全，也避免未登录用户看到轮播图。
