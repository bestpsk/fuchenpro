# 轮播图上传成功后预览不显示修复

## 问题分析

上传成功后 `form.value.image = res.fileName`，后端返回的 `fileName` 格式为 `20260525/abc123def456.jpg`（不含 `/profile/upload/` 前缀）。

而 `getImageUrl()` 拼接方式为 `VITE_APP_BASE_API + url`，结果变成：
```
http://localhost:8080/20260525/abc123def456.jpg
```
缺少 `/profile/upload/` 路径段，导致 404 无法显示图片。

后端上传接口实际返回两个字段：
- `fileName`: `20260525/abc123def456.jpg` — 仅日期+文件名
- `url`: `/profile/upload/20260525/abc123def456.jpg` — 完整相对路径

应使用 `res.url` 而非 `res.fileName`。

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：将 res.fileName 改为 res.url

```javascript
// 修改前
form.value.image = res.fileName

// 修改后
form.value.image = res.url
```

这样 `getImageUrl()` 拼接后为 `http://localhost:8080/profile/upload/20260525/abc123def456.jpg`，路径正确，图片可正常显示。

如果是 COS 云存储，`res.url` 返回的是完整 HTTPS URL（以 `http` 开头），`getImageUrl()` 中 `url.startsWith('http')` 判断会直接返回，也兼容。
