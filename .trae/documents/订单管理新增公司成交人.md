# 订单管理 - 新增公司成交人（开单员工）显示

## 需求
在AppV3订单管理中，除了显示"门店成交人"外，还要显示"公司成交人"（即开单员工 `creator_user_name`）。管理者需要看到所有管理员工的订单，知道是哪个员工开的单。

## 现状分析

### 数据库
- `store_dealer` — 门店成交人（varchar(100)，手动输入，可为NULL）
- `creator_user_name` — 开单员工姓名（varchar(50)，系统自动填充）
- `creator_user_id` — 开单员工ID（bigint(20)，系统自动填充）

### PC端（已有）
- [front/src/views/business/order/index.vue](file:///f:/fuchen/front/src/views/business/order/index.vue) 已有两列：
  - 第59行：`<el-table-column label="门店成交人" prop="storeDealer" />`
  - 第94行：`<el-table-column label="开单员工" prop="creatorUserName" />`
  - 详情页也有对应展示

### AppV3（缺少）
- [order/index.vue:59](file:///f:/fuchen/AppV3/src/pages/business/order/index.vue#L59) — 只有"成交人"（store_dealer），缺少"开单员工"（creator_user_name）
- [order/detail.vue:31-34](file:///f:/fuchen/AppV3/src/pages/business/order/detail.vue#L31-L34) — 只有"成交人"（storeDealer），缺少"开单员工"（creatorUserName）

## 修改方案

### 步骤1：订单列表页 `order/index.vue` — 新增开单员工显示

在订单卡片的 `info-row` 中，将"成交人"改为"门店成交人"，并在同一行或新增一行显示"开单员工"。

当前布局：
```
客户 | 门店
成交人 | 金额
时间
```

修改后布局：
```
客户 | 门店
门店成交人 | 开单员工
金额 | 时间
```

### 步骤2：订单详情页 `order/detail.vue` — 新增开单员工显示

在"成交人"行下方新增"开单员工"行，显示 `creatorUserName` 或 `creator_user_name`。

### 步骤3：开单记录页 `sales/order.vue` — 开单记录中也显示开单员工

开单记录列表中已有 `creatorUserName` 的引用（第161行），确认是否正确展示。
