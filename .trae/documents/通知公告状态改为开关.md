# 通知公告状态改为开关 - 实施计划

## 需求

将通知公告列表的"状态"列从字典标签显示改为 el-switch 开关，可直接在列表中切换启用/关闭。

## 实施步骤

### 步骤 1：前端 - 状态列改为 el-switch

**文件**: `front/src/views/system/notice/index.vue`

将第 84-88 行的状态列：
```html
<el-table-column label="状态" align="center" prop="status" width="100">
  <template #default="scope">
    <dict-tag :options="sys_notice_status" :value="scope.row.status" />
  </template>
</el-table-column>
```

改为：
```html
<el-table-column label="状态" align="center" prop="status" width="100">
  <template #default="scope">
    <el-switch
      v-model="scope.row.status"
      :active-value="'0'"
      :inactive-value="'1'"
      @change="handleStatusChange(scope.row)"
      v-hasPermi="['system:notice:edit']"
    />
  </template>
</el-table-column>
```

### 步骤 2：前端 - 新增 handleStatusChange 方法

在 script 中添加状态切换处理函数：

```js
function handleStatusChange(row) {
  let text = row.status === "0" ? "启用" : "关闭"
  proxy.$modal.confirm('确认' + text + '公告"' + row.noticeTitle + '"？').then(() => {
    return updateNotice({ noticeId: row.noticeId, status: row.status })
  }).then(() => {
    proxy.$modal.msgSuccess(text + "成功")
  }).catch(() => {
    row.status = row.status === "0" ? "1" : "0"
  })
}
```
