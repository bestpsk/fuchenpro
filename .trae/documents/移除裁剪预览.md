# 移除裁剪预览功能

## 修改文件

`front/src/views/system/banner/index.vue`

## 实施步骤

### 步骤1：移除预览区域 HTML

删除裁剪弹窗中右侧的预览 `el-col`，左侧裁剪区域改为全宽。

### 步骤2：移除 realTimeCrop 回调函数

不再需要实时预览回调。

### 步骤3：移除预览相关 CSS

删除 `.crop-preview`、`.crop-preview-title`、`.crop-preview-box` 样式。

### 步骤4：移除 @realTime 事件绑定

vue-cropper 组件上不再绑定 `@realTime` 事件。
