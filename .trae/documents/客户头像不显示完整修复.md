# 创建/修改顾客后头像不显示 - 完整修复计划

## 问题现象
创建顾客时选择了头像，添加成功后客户列表仍显示名字首字母，不显示头像图片。

## 完整数据流追踪与断点分析

### 流程1：创建客户（sales/index.vue 弹窗）

```
1. 用户选择图片 → customerAvatarPreview = 本地临时路径
2. 提交表单 → addCustomer(data) → 后端返回 {code:200, msg:"", customerId:123}
3. newCustomerId = res?.customerId → 应该能拿到123 ✓
4. uploadCustomerAvatar(123, 临时路径) → uni.uploadFile → 后端avatar()方法
5. 后端avatar() → COS上传/本地存储 → 更新数据库avatar字段 → 返回{code:200, imgUrl:"..."}
6. closeAddCustomerPopup() → loadCustomerList() → searchCustomer() → 刷新列表
```

### 断点1：`u-avatar` 的 `src` 和 `text` 互斥逻辑有缺陷

当前代码：
```html
<u-avatar :src="getAvatarUrl(item.avatar)" :text="item.avatar ? '' : (item.customerName ? ...)" />
```

**问题**：当 `item.avatar` 有值但图片加载失败时（URL无法访问），`text` 为空字符串，`src` 指向一个无法加载的URL，`u-avatar` 会显示空白而不是回退到文字头像。

**修复**：不依赖 `item.avatar` 判断是否显示文字，而是始终设置 `text`，让 `u-avatar` 在图片加载失败时自动回退。

### 断点2：`getAvatarUrl()` 对空字符串的处理

`item.avatar` 可能是空字符串 `''`（数据库默认值），`getAvatarUrl('')` 返回 `''`，然后 `src=''`，`u-avatar` 可能不会正确处理空src。

**修复**：`getAvatarUrl` 对空字符串也返回空，同时 `text` 始终设置为首字母。

### 断点3：COS上传的图片URL可能无法在App端直接访问

如果COS返回的是完整URL（如 `https://xxx.cos.ap-shanghai.myqcloud.com/customer_avatar/xxx.png`），`getAvatarUrl` 会直接返回，这应该没问题。

如果是本地存储返回相对路径（如 `/profile/customer_avatar/xxx.png`），`getAvatarUrl` 拼接为 `/prod-api/profile/customer_avatar/xxx.png`，需要代理能正确转发。

### 断点4：客户编辑页面保存后头像可能未正确上传

`customer/detail.vue` 中 `submitForm()` 先调用 `updateCustomer(data)` 保存基本信息，然后调用 `uploadAvatar()` 上传头像。但 `uploadAvatar` 使用 `avatarTempFile.value`，这个值只在 `chooseAvatar()` 时设置。

**问题**：如果用户只修改了文字信息没有更换头像，`avatarTempFile` 为空，不会触发上传，这是正确的。但如果用户更换了头像，上传应该能正常工作。

### 核心修复方案

**最可靠的方案**：将头像上传改为**先上传再保存**，即：
1. 用户选择图片后立即上传，获取URL
2. 将URL作为表单字段 `avatar` 一起提交保存
3. 这样不需要单独的头像上传接口，也不需要先创建客户再上传

但这个方案需要修改后端 `add()` 和 `edit()` 方法支持 `avatar` 字段（已支持，因为在 `$fillable` 中）。

**更简单的修复**：保持当前架构，修复 `u-avatar` 的回退逻辑。

## 修改方案

### 步骤1：修复 `u-avatar` 回退逻辑（sales/index.vue 客户列表）

始终设置 `text` 为客户名首字，当 `src` 有值时 `u-avatar` 会优先显示图片，图片加载失败时自动显示文字。

```html
<u-avatar :src="getAvatarUrl(item.avatar)" :text="item.customerName ? item.customerName.charAt(0) : ''" ... />
```

### 步骤2：修复 `u-avatar` 回退逻辑（customer/detail.vue 编辑页）

同样始终设置 `text`。

### 步骤3：修复 `u-avatar` 回退逻辑（OrderList.vue 首页订单列表）

同样始终设置 `text`。

### 步骤4：修复 `getAvatarUrl()` 对空字符串的处理

```javascript
function getAvatarUrl(avatar) {
  if (!avatar || avatar === '') return ''
  if (avatar.startsWith('http://') || avatar.startsWith('https://')) return avatar
  return config.baseUrl + avatar
}
```
