## 实施步骤

### 步骤 1：后端 - 增强 listTop 接口返回 unreadCount

**文件**: `webman/app/controller/system/SysNoticeController.php`

修改 `listTop` 方法，在响应中增加 `unreadCount` 字段：

```php
public function listTop(Request $request)
{
    $service = new SysNoticeService();
    $notices = $service->listTop($request->loginUser->userId);
    $unreadCount = $notices->where('read', false)->count();
    return AjaxResult::success([
        'list' => $notices,
        'unreadCount' => $unreadCount
    ]);
}
```

**文件**: `webman/app/service/SysNoticeService.php`

确保 `listTop` 返回的 `read` 属性名与前端 `isRead` 对应（检查是否有驼峰转换中间件）。如果存在转换，则无需修改；否则需在模型中添加 accessor 或在 service 中手动转换。

### 步骤 2：APP 端 - 创建通知公告 API 文件

**新建文件**: `AppV3/src/api/system/notice.js`

参照 Web 端 `front/src/api/system/notice.js` 和 App 端现有的 API 模式（如 `api/system/user.js`），创建以下接口：

```js
import request from '@/utils/request'

export function listNoticeTop() {
  return request({ url: '/system/notice/listTop', method: 'get' })
}

export function listNotice(query) {
  return request({ url: '/system/notice/list', method: 'get', params: query })
}

export function getNotice(noticeId) {
  return request({ url: '/system/notice/' + noticeId, method: 'get' })
}

export function markNoticeRead(noticeId) {
  return request({ url: '/system/notice/markRead', method: 'post', params: { noticeId } })
}

export function markNoticeReadAll() {
  return request({ url: '/system/notice/markReadAll', method: 'post' })
}
```

### 步骤 4：APP 端 - 改造 NoticeBar 通知栏

**文件**: `AppV3/src/components/home/NoticeBar.vue`

- 移除硬编码数据
- 引入 `listNoticeTop` API，动态加载通知列表
- 将 `notice_type`（1=通知, 2=公告）映射为中文标签
- 显示 `notice_title` 作为通知内容
- 点击"查看更多"跳转到通知公告列表页
- 点击单条通知跳转到通知详情页
- 无通知时隐藏整个组件（已有 `v-if`）

关键改动：
```js
import { listNoticeTop, markNoticeRead } from '@/api/system/notice'

const noticeList = ref([])

const typeMap = { '1': '通知', '2': '公告' }

function loadNotices() {
  listNoticeTop().then(res => {
    const list = res.data.list || res.data || []
    noticeList.value = list.map(item => ({
      ...item,
      typeLabel: typeMap[item.noticeType] || '消息',
      content: item.noticeTitle
    }))
  }).catch(() => {})
}

function handleMoreNotice() {
  uni.navigateTo({ url: '/pages/system/notice/index' })
}

function handleNoticeClick(item) {
  if (!item.isRead && !item.read) {
    markNoticeRead(item.noticeId).catch(() => {})
  }
  uni.navigateTo({ url: `/pages/system/notice/detail?noticeId=${item.noticeId}` })
}

onMounted(() => loadNotices())
```
